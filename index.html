Problem Statement SIH26124[cite: 2, 3]

PRAYAAN — AI-Powered Urban Intelligence Platform

Category: Software | Theme: Smart Automation & Urban Mobility[cite: 2, 3]

Concept & Core Value

Turns Chennai's public bus fleet into a moving sensor network[cite: 2, 3]. Edge modules on-board each bus run lightweight ML inference and stream classified events to a central backend for live urban governance[cite: 2, 3].

5 Layers of Route Sensing[cite: 2, 3]

  • GPS & Congestion: Real-time positions and delay heatmaps[cite: 2, 3].
  • Air Quality (AQI): Continuous mapping of PM2.5, PM10, NO₂, CO, O₃[cite: 2, 3].
  • Potholes: Vibration-ML classifier with GPS tagging[cite: 2, 3].
  • Civic Issues: Vision-based waterlogging and street light fault flags[cite: 2, 3].
  • Fleet Health: Battery and module uptime heartbeats[cite: 2, 3].

Architecture & Data Scale[cite: 2, 3]

FastAPI Backend (Port 8000) handling REST + WebSockets connected to SQLite (`prayaan.db`) and React Leaflet.js dashboard[cite: 2, 3]. Simulated using 50 buses across 10 MTC Chennai routes generating ~55,000 events/day[cite: 2, 3].

SmartTraffic — Network-Aware Signals

Team Leader: Rishab C V (24BCE5296)[cite: 4]

Core Innovation (`predictive-pressure-v1`)[cite: 4]

Unlike traditional local adaptive signals that move queues to the next junction, our algorithm forecasts downstream capacity with a downstream penalty of 0.45 and trend weight of 0.8 to prevent corridor gridlock[cite: 4].

Key Systems Built[cite: 4]

  • Emergency Green Corridor: Dynamic lead/hold timing for ambulances with measured post-pass recovery[cite: 4].
  • Dual Engine Architecture: Deterministic 4-junction lab + SUMO/TraCI microscopic simulator[cite: 4].
  • Live Control Room: React/Vite dashboard displaying network congestion heatmaps, +15-tick forecasts, and throughput[cite: 4].
